# 固化输出模板（gold-price × news-summary 共用）

**⚠️ 本文为「可复制骨架」主文件。** 每次生成日报/汇总时，**第一步先贴对应模板骨架，再替换** **`{占位符}`**——禁止临场造句、跳过骨架直接输出。硬性。

> **用途：** 每次生成「黄金日报」或「新闻汇总」时，**直接复制下方对应模板骨架，填入当日数据**，不再每次临场造句。
> **规则：** ① 模板骨架固定不变（结构/标题/检查项）；② 只填数据，不改结构；③ 数据失效时按「数据失效护栏」显式标注，禁估算填充；④ **六维度任一项 ❌ = 汇总不完整 → 必须先补搜重出，再交付**。
> **引用：** news-summary/SKILL.md「C0 黄金日报硬联动」与 gold-price/SKILL.md「新闻汇总联动」均以本文为准，不各自维护模板，防两处漂移。

**模板 v2 新增说明（2026-09-03）：** 针对对比复盘补入 3 个增量点，以下各处已用 `★ 增量` 标注：

1. **外网具名源优先级** — 关键数据必须列来源全称（ADP官方/FXEmpire/Crux/TradingKey 等），禁止仅写「新浪/财联社」一笔带过；外网与中文源同级、不可省略。
2. **机构/分析师预测层** — 新增「机构/预测」小节，收录金价目标位、加息概率 vs 实际利率背离类观点；**增量规则：单条机构观点做方向一致性核验，逻辑自相矛盾（如利多却报下行目标）须标注存疑，不照搬**。
3. **持仓分档联动** — 快照外补「分档操作语境」：浮亏变化路径、分档接货回本、触发线。

## 一、数据失效护栏（每次填模板前先对照）

| 必选项      | 拉不到数据时                        |
| :------- | :---------------------------- |
| ① 当前金价   | 显式输出「⚠️ 无法获取实时金价」，禁估算/记忆值当确定值 |
| ② 持仓快照   | 明说「无持仓快照数据」，禁编克重/均价           |
| ③ 本周关键数据 | 标注「数据日历待核」，禁编日期/数值            |
| ④ 外网重磅   | 只列「近期记忆主线、待核实」，禁虚构来源          |

## 二、黄金日报标准模板

```
# 🥇 黄金日报 — {YYYY}年{MM}月{DD}日 {周} {HH:mm}

## 📊 当前金价
| 项目 | 数据 |
|:-----|:-----|
| **XAU/USD** | **${price}**（gold-api / goldprice.today 双源交叉✅，偏差<0.5%）|
| **人民币/克** | **¥{price_cny}** |
| **日内区间** | ${low} – ${high} |
| **数据时间** | {来源时间} |

## 💼 持仓快照
| 项目 | 数据 |
|:-----|:-----|
| **总持仓** | 70.37g（工行40.37g + 招行30g）|
| **加权均价** | ~¥1,030/g（~$4,715 回本线）|
| **当前浮亏** | **-{pct}%**（金价 ${price} / ¥{price_cny}）|
| **距回本** | 金价需 +{gap}%（$4,715）|

## 📅 本周关键数据
| 日期 | 事件 | 重要性 |
|:----:|:-----|:------:|
| {day} | {事件} | ⭐ |

## 📰 外网重磅（必盯信号）
- {贝森特/特朗普涉债/美债收益率/沃什/达利欧 任一命中}

## 🧭 今日判断
- 短期：{承压/反弹/震荡}，关键支撑 {level}，阻力 {level}
- 长期：{美元信用/央行购金/美国扛不住加息} 逻辑不变
```

## 五、完整输出示例（以 2026-09-01 为样例，照此格式执行）
