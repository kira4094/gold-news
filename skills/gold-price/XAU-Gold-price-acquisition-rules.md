# XAU/USD 现货黄金实时价格获取规则

## 🔴 强制双源交叉验证 + 合理性门禁（2026-08-26 新增，硬性）

> **背景：** 2026-08-25 曾因"单源单次拉取"报错价（gold-api 返回 $4,601，实际 $4,656，差 $55）。**金价是硬数据，禁止单源采信。**

### 步骤（每次报金价必走）

```
1. 源A：gold-api.com/price/XAU 拉一次
2. 源B：goldprice.today/api.php?data=live（Node 精确取 USD.ounce）
3. 对比两值：
   ├─ 相差 ≤0.5% → 采信（输出标"双源确认"）
   ├─ 相差 >0.5% → 拉第三源（东方财富 browse CLI）裁决
   └─ 相差 >1%   → 标红"⚠️ 价格异常，两源偏差>1%，待重核"，不直接采信
4. 与上次报的价值对比：
   ├─ 偏离 ≤1% → 正常
   └─ 偏离 >1% → 标"较上次变动 X%"，确认非过期缓存
5. 黄金日报标注：金价来源 + 更新时间
```

### 硬性要求

- **任何金价输出 = 至少双源确认**，单源不算数
- 拿到的价与上次对比，异常就重核，不硬报
- 有怀疑 → 明说"此价待核"，不报给用户当确定值
- 输出格式统一：`金价来源：{源A}+{源B}（更新 {时间}）`

### 获取命令（ctx_execute / Node.js）

```javascript
const https = require('https');
function fetch(url) {
  return new Promise((resolve, reject) => {
    https.get(url, { headers: { 'User-Agent': 'curl/8.0' } }, (res) => {
      let data = '';
      res.on('data', chunk => data += chunk);
      res.on('end', () => resolve(data));

(async () => {

  const j = JSON.parse(r);
  console.log(`USD: $${j.USD.ounce}/oz  CNY: ${j.CNY.gram}元/g`);
})();
```

## 方法2B：国际暗金价格（周末/非交易时段参考）

**用于周末、节假日等非交易时段查看金价走势。** 通过 PAX Gold（PAXG）加密货币代币价格获取——PAXG是1:1锚定黄金的ERC-20代币，在Kraken/MetaMask等平台7×24小时真实交易，比任何"暗金参考指标"都更准确。

### 页面地址
- https://www.kraken.com/zh-cn/prices/pax-gold — Kraken PAXG价格（24h价差参考）
- https://metamask.io/zh-CN/price/pax-gold — MetaMask PAXG价格（含历史走势）

### 获取方式（ctx_execute）

```javascript
// Kraken PAXG — 7×24真实黄金价格，周末最准
const r = await fetch('https://www.kraken.com/zh-cn/prices/pax-gold');
const text = await r.text();
// 提取 $X,XXX.XX 格式的价格
const priceMatch = text.match(/\$[0-9,]+\.[0-9]{2}/);
const price = priceMatch ? priceMatch[0].replace(/,/g,'').replace('$','') : '—';
```

### 可获得数据
- PAXG/USD 实时价格
- 24小时高/低
- 历史最高/最低

### 特点
- ✅ **7×24小时真实交易**，不是参考指标
- ✅ 1:1锚定黄金（每枚PAXG对应1金衡盎司黄金）
- ✅ 两个平台互相验证，价格一致
- ✅ 有真实成交量支撑
- ⚠️ 极低流动性时段价差可能略大（周末亚洲深夜）

### 备用暗金来源（拉不到时尝试）

|:--------|:-----|
| **GoldPrice.Today** → `USD.ounce` / `CNY.gram` | 同方法1共享 |

- Kalshi 是"钱"在定价（下注的人拿真钱说话，骗不了人）
- 华尔街已开始把 Kalshi 当"新传声筒"——市场对 Fed 放风的信任在下降

**追踪规则：**
- 每次新闻汇总时，查看 Kalshi 上"美联储9月加息/降息概率"实时赔率
- 概率下降 = 市场真金白银押"转鸽" = 利多黄金
- 概率上升 = 市场押"加息" = 利空黄金
- 与传声筒口径对比：若传声筒放鹰但 Kalshi 概率降 → 嘴鹰无效，信 Kalshi

## 🤖 AI 泡沫破裂前瞻指标追踪（黄金主升的先行信号）

**背景：** 判断"AI 泡沫破裂 → 资金回流黄金 → 黄金主升"的关键，不是看 AI 股价本身，而是盯"发行人出货"和"基本面恶化"的前瞻信号。黄仁勋/马斯克等是泡沫"发行人"——他们比谁都清楚泡沫，边画饼边落袋。

**四大核心指标（每次新闻汇总检查）：**

### ① AI 头部大额减持 🚨 最高优先级
```
盯谁：
→ 黄仁勋（英伟达）减持节奏
→ 马斯克（特斯拉/xAI）减持
→ OpenAI/微软/谷歌高管内部交易（insider selling）
→ 半导体高管集体减持（台积电/AMD/博通）

信号含义：
→ 高管开始大额减持 = 发行人出货加速 = 泡沫接近顶部
→ 集体减持（多家同时）= 泡沫破前最强信号
```

### ② 各家 AI 财报
```
盯什么：
→ 英伟达：指引（guidance）是否下调（画饼乏力 = 泄气开始）
→ 微软/谷歌/Meta：AI 资本开支 vs 收入兑现
→ CoreWeave：亏损扩大速度 vs 订单（债务风险）
→ Arm/AMD/博通：增速是否见顶

信号含义：
→ 指引不及预期 = 画饼画不动 = 泡沫开始泄气
→ 资本开支增速见顶 = AI 烧钱减速 = 泡沫失去燃料
→ 财报"指引下调"比"利润下滑"更关键（前瞻信号）
```

### ③ 数据中心利用率
```
盯什么：
→ 数据中心空置率/利用率（行业报告）
→ 美国电力需求增速（AI 抢电 → 若电力不足 = 扩张受限）
→ 新建数据中心 vs 实际算力需求

信号含义：
→ 利用率下降 = "暗光纤"重演（建了没人用）= 泡沫破前奏
→ 电力瓶颈 = AI 扩张天花板 = 资本开支见顶
→ 这是判断"需求追不上供给"的最直接指标
```

### ④ AI 融资/债务环境
```
盯什么：
→ AI 公司发债规模（Alphabet 发澳元债、CoreWeave 债务）
→ 融资利率（加息 → AI 融资成本升 → 算不过账）
→ AI 初创融资估值（Databricks $1900 亿等）是否见顶

信号含义：
→ 融资变难/变贵 = 烧钱模式撑不住 = 泡沫破的燃料
→ 估值见顶 = 新钱不愿进 = 泡沫停止膨胀
```

**当前记录（2026-08）：**
| 指标 | 当前状态 | 信号 |
|:-----|:---------|:-----|
| 简街做多爆仓 $150亿 | 8/15 已爆（AI 神童基金） | 🔴 第一个杠杆玩家受伤 |
| 英伟达/马斯克减持 | 需跟踪（2025-26 已有多次） | 🟡 持续关注 |
| 数据中心利用率 | 需跟踪（暗光纤风险） | 🟡 潜在 |
| AI 财报指引 | 8月底 Nvidia 财报是观察窗 | 🟡 待验证 |

**判断框架：**
```
如果 2+ 项同时转红（减持加速 + 指引下调 + 利用率降）：
→ AI 泡沫破裂确认 → 资金逃离 AI → 避险黄金 → 你的主升启动

如果只有 1 项（如简街爆仓）：
→ 早期预警，泡沫可能反弹（像 2000 年多次假破）
→ 继续持有黄金，别急
```
