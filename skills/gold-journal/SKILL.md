# Gold Journal — 黄金会话文字归档

把黄金相关对话持续整理为可追溯的月度 Markdown 草稿，并在月底生成正式会话记录与持仓备忘录。

## 强制边界

- “记录/录入”只指把对话内容整理为文字写入 Markdown；不录音，不采集或保存音频。
- 本技能是**后处理步骤**。若同轮触发 `news-summary` 或 `gold-price`，先完整执行对应技能、联网检索、双源金价、六维新闻、来源核验、宏观日历与持仓分析，再归档。
- 不得为了节省归档时间而缩短主要回答、减少来源、跳过模板或降低分析质量。
- 归档失败不改变主要回答。先保留完整回答，再简短说明归档失败及可恢复方式。
- 不把月度记录写进插件仓库；仓库只存技能规则和黄金数据追踪表。
- 不保存凭据、令牌、隐藏系统信息或内部推理。保存“结论及其可解释依据”，不声称保存不可见的思维链。

## 触发与顺序

### 自动追加

以下任一内容出现时，在本轮主要任务完成后自动追加，不再询问用户是否记录：

- 新闻汇总、黄金日报、金价或贵金属走势；
- CPI、PPI、PCE、非农、ADP、初请、PMI、GDP、FOMC、Fed 官员或“传声筒”；
- 美债收益率、财政部发债/回购、美元、实际利率；
- 石油、霍尔木兹、红海、美伊、俄乌等影响黄金的能源与地缘链；
- AI资本开支、能源需求、融资环境、政治风险对黄金的传导；
- 用户持仓、买卖计划、回本线、风险偏好、担忧和判断变化；
- Gold & News 插件、技能模板、数据源、版本或归档工作流讨论。

### 手动整理

用户说“补录讨论”“更新草稿”“生成月报”“会话记录”“持仓备忘录”或类似请求时，直接执行对应归档模式。

### 固定执行顺序

```text
识别主要任务
→ 完整执行 gold-price / news-summary 或其他分析
→ 形成并核验主要回答
→ 调用 gold-journal 追加文字记录
→ 向用户交付主要回答；仅在归档失败时附加简短提示
```

## 草稿定位与持久化

1. 以联网获得或同轮上游技能已核验的北京时间确定月份。可复用同轮已经验证的时间，避免重复联网。
2. 默认草稿名为 `{中文月份}黄金分析会话记录草稿.md`，例如 `九月黄金分析会话记录草稿.md`。
3. 优先更新用户明确指定或当前已打开的草稿；否则按环境选择：
   - 本地桌面环境：`D:\WindowsOS\OneDrive\应用\文档\gold-price-memary\`；
   - 云端环境：查找并更新同名持久文件，保持原文件身份与版本历史；
   - 无持久写入能力：生成同名可下载文件，并明确提醒用户保存。
4. 更新前读取最新版本，保留全部已有内容；使用版本保护或等效机制。发生冲突时重新读取、合并本轮增量后再写，禁止用旧副本覆盖新内容。
5. 不存在当月草稿时创建，并写明记录期间、上月持仓基线、承接文件和记录约定。
6. 联网取时失败时，不阻塞普通对话归档；使用“北京时间待核”标记。若同轮是新闻汇总/实时金价，仍遵守上游技能的暂停规则。

## 每轮追加规则

写入前按主题、时间和关键数据检查最近条目，避免重复。然后按 [归档格式](references/archive-format.md) 追加。

必须保留：

- 用户实际提出的问题、观点、假设和情绪变化；
- 回答给出的结论、因果链、场景条件和风险边界；
- 关键数值、发布时间、市场反应及其来源；
- “已确认事实 / 用户判断 / 助手推演 / 待核消息 / 后续修正”的状态；
- 持仓数量、成本、回本线、实际操作与策略变化；
- 数据或判断出现矛盾时的纠正过程，不用新结论抹掉旧判断。

可以压缩：

- 重复的“新闻汇总”等触发口令；
- 与前一条完全相同且没有新数据或新判断的内容；
- 工具调用过程、搜索词调试和对用户无长期价值的界面操作。

压缩不等于省略：只要一次重复请求产生了新新闻、新报价、新解释或新判断，就必须记录对应增量。

## 历史补录

- 补录范围按用户要求覆盖整月或指定历史区间，不只处理当天消息。
- 使用当前可见会话、用户提供的历史文件和已经持久化的草稿；不得凭空重建不可见对话。
- 七月、八月材料作为九月成稿的承接背景时，保留持仓基线、分析框架和纠错记录，但不要把历史内容伪装成本月新事件。
- 若多个历史文件对同一数值不一致，保留各自时间口径，并在“数据校正”中说明差异。

## 月末成稿

**触发：** 每月最后一天、月末计划任务、用户要求生成月报，或下月首次归档时发现上月尚未收官。

1. 读取整个月草稿，而不是只读最后一天；同时读取用户提供的前月会话记录和持仓备忘录。
2. 对月末金价、汇率、持仓、FOMC、就业/通胀数据、美债回购和重要地缘事实联网复核。
3. 生成两个文件：
   - `{月份}黄金分析会话记录.md`
   - `{月份}黄金分析与持仓备忘录.md`
4. 会话记录保留时间线、用户观点、分析演化、预测与事后验证；备忘录聚合持仓、月度行情、宏观框架、风险、策略和下月节点。
5. 对错误预测采用“当时判断 → 实际结果 → 原因修正”，不得事后改写成一直正确。
6. 按 [归档格式](references/archive-format.md) 校验完整性后，保存到与草稿相同的位置；草稿继续保留，不用正式稿覆盖。

## 与同插件技能的关系

- `../news-summary/SKILL.md`：负责新闻检索、分类和二合一输出；完成后本技能归档增量。
- `../gold-price/SKILL.md`：负责金价、宏观、持仓计算和行情解释；本技能只消费其已核验结果，不重复降低精度的估算。
- `../gold-price/黄金数据追踪表.md`：记录结构化宏观数据，仍留在插件仓库；月度会话草稿不替代它。
- 月报生成涉及当前行情时，先执行 `gold-price`；涉及当日新闻时，先执行 `news-summary`。
