# 黄金会话归档格式

本参考仅在追加草稿、补录历史或生成月末正式文件时读取。

## 一、单轮草稿条目

```markdown
## 【MM/DD HH:mm】主题

**记录类型：** 新闻汇总 / 行情分析 / 宏观数据 / 地缘能源 / 持仓策略 / 方法修正

### 用户关注
- 用户的问题、观点或担忧。

### 数据与事实
| 项目 | 数值/事件 | 时间口径 | 状态与来源 |
|:---|:---|:---|:---|
| ... | ... | 北京时间... | 已确认；[来源](URL) |

### 分析与结论
- 因果链和结论。
- 生效条件、反向风险和时间尺度。

### 修正与待核
- 当时预测、后续修正或仍需验证的事项。

### 持仓影响
- 仅记录实际持仓变化、用户明确策略或与回本线相关的结果；无变化可省略。
```

按内容删去空节，不为了凑模板制造信息。普通短讨论可合并成三至六条项目，但仍须保留事实状态、推理链和修正。

## 二、事实状态标签

| 标签 | 用途 |
|:---|:---|
| `已确认` | 官方数据、可靠实时行情或多源一致事实 |
| `用户判断` | 用户提出的观点、情景或价格预期 |
| `助手推演` | 基于已知信息的条件性分析，不是假定事实 |
| `待核` | 单一来源、突发地缘消息、未发布数据或接口异常值 |
| `后续修正` | 新数据推翻、修订或限定此前判断 |

不要把“用户判断”或“助手推演”改写成已经发生的事实。

## 三、去重与合并

- 以“北京时间 + 主题 + 关键数值/事件”识别重复条目。
- 同一事件的新价格、新数据或新解释追加到原主题的后续条目，不删除旧快照。
- 完全重复的触发口令不单独建节；其产生的新汇总必须建节或补充现有节。
- 同一数值有不同来源时并列记录时间戳；确认接口延迟后标记后续修正。
- 文件版本冲突时，以最新文件为基线重新应用本轮增量，不整文件覆盖。

## 四、月度会话记录结构

```markdown
# {月份}黄金分析会话记录

**记录期间：** YYYY-MM-01 — YYYY-MM-DD
**承接基线：** 上月末金价、持仓、核心矛盾

## 〇、月度总览
## 一、第一周（日期）：主线
## 二、第二周（日期）：主线
## 三、第三周（日期）：主线
## 四、第四周（日期）：主线
## 五、月末收官
## 六、方法论与工具修正
## 七、持仓与心态演化
## 八、预测验证与下月关注
```

每周按真实事件组织，不强行平均篇幅。保留关键盘面、数据、用户洞察、助手判断和后续验证。

## 五、月度持仓备忘录结构

```markdown
# {月份}黄金分析与持仓备忘录

**更新日期：** YYYY-MM-DD
**月末金价：** XAU/USD + 人民币/克 + 时间与来源
**持仓状态：** 克重、人民币成本、浮盈亏、动态美元回本线

## 一、持仓汇总
## 二、月度大事记
## 三、核心宏观与黄金框架
## 四、策略执行与风险边界
## 五、本月预测复盘
## 六、下月关键节点
## 七、待办与数据核验
```

### 持仓计算口径

- 人民币总成本和克均成本是主锚；美元/盎司回本线随 USD/CNY 变化，必须按月末实时汇率重算。
- 银行手续费计入对应账户成本。
- 没有用户确认的成交，不得从“计划买入”推断为实际持仓。
- 不展示用户未要求展开的隐私资产；仅写已经纳入黄金归档的持仓信息。

## 六、月末校验表

- [ ] 已遍历整月草稿及用户提供的前月材料
- [ ] 月末金价和人民币价至少双源核验
- [ ] 宏观实际值与发布时间来自官方或一级来源
- [ ] 地缘突发消息区分确认与待核
- [ ] 所有预测均能找到当时记录和事后结果
- [ ] 持仓克重、成本、浮盈亏和回本线计算一致
- [ ] 正式会话记录与备忘录均已生成，草稿仍保留
